# SmartVend MIPS 🥤

Projeto de uma máquina de vendas desenvolvido em Assembly MIPS como parte da disciplina de **Arquitetura e Organização de Computadores**, da Universidade Federal de São Paulo (UNIFESP).

## Sobre o projeto

O SmartVend MIPS consiste no desenvolvimento de um simulador de máquina de vendas, no qual o usuário poderá consultar produtos, inserir dinheiro, realizar compras e verificar o estoque disponível.

O projeto tem como objetivo aplicar os conceitos estudados na disciplina por meio da criação de um programa interativo utilizando Assembly MIPS e o simulador MARS.
